## Recolour note
The default (`wallpaper.jpg` / `wallpaper-midnight.jpg`, same file) is the
Milad Fakurian photo hue-remapped to the cyan house accent (2026-11-12,
piecewise hue map, saturation and value untouched): the violet field became
deep blue and the magenta glow became cyan. Hue check after the recolour:
violet+magenta 0.0% of saturated pixels (was 100%), cyan 9.4%, blue 90.6%.
The original magenta version is the same Unsplash photo, recoverable from
the artist's collection above (original md5 `f16a7e149ee7a5e6264a9fd8c9d1db48`).

## AI-generated wallpapers (2026-11-14)

`wallpaper-mist.jpg`, `wallpaper-forest.jpg`, `wallpaper-dune.jpg`,
`wallpaper-hex.jpg`, `wallpaper-storm.jpg` and `wallpaper-lake.jpg` were
generated for VELTRIX with an image model (no third-party photo, no
Unsplash license — original generations for this project, dark cinematic
minimalism in the house taste). They ship alongside the Unsplash set above
and are picked up by the same install step (`install.sh` copies
`defaults/wallpaper/*.jpg` to `/usr/share/veltrix/wallpapers/`).
